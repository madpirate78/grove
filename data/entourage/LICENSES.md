# Entourage Library Licences

This directory contains scraped entourage symbols used as scale references in Grove plans.
Each entry below records the source, author, and licence for every file shipped in `data/entourage/`.

This file is generated by `scripts/fetch_entourage.py` from `scripts/entourage_manifest.toml`. Do not edit by hand — update the manifest and re-run the script.
